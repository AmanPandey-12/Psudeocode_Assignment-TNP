## 🧠 IMPORTANT THEORY

### 🔹 Function
* Takes input
* Returns an output value

### 🔹 Procedure
* Performs a task
* Has no return value (e.g., `void`)

👉 **Formula:**  
`Function = Input → Process → Output`
