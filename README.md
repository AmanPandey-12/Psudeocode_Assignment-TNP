## 🧠 IMPORTANT THEORY

### 🔹 Function
* Takes input
* Processes it
* Returns an output value

### 🔹 Procedure
* Performs a task
* Has **no return value** (declared as `void`)

👉 **Formula:**
`Function = Input → Process → Output`
